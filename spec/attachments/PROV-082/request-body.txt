--- Scenario D: USER base64 image with detail=Some(Auto) — the FIX ---
  UserContent::image_base64(img.data, media_type, Some(ImageDetail::Auto))

RESULT: SUCCESS
  [
    {
      "role": "user",
      "content": [
        {
          "type": "image_url",
          "image_url": {
            "url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAE...=",
            "detail": "auto"
          }
        }
      ]
    }
  ]

  Setting detail to Some(ImageDetail::Auto) at the image_base64 call sites
  makes the conversion succeed. Wire body shape matches what vLLM accepts
  (verified separately via direct curl that returned a real description).
